# 盆腔炎性疾病

盆腔炎性疾病（pelvic inflammatory disease，PID）是上生殖道感染和炎症的综合征，可包括子宫内膜炎、输卵管炎、输卵管卵巢脓肿和盆腔腹膜炎。它不是仅凭“盆腔疼痛”就能确定的单一疾病。[^1][^3][^4]

PID 常由阴道或宫颈的微生物向上蔓延引起。沙眼衣原体和淋病奈瑟菌是重要病原体，但也可能有多种其他微生物参与；诊断 PID 不等于一定存在某一种性传播感染，也不能据此推断伴侣不忠。[^1][^4]

!!! info "健康教育提示"
    本文用于帮助理解 PID 的症状、检查和治疗原则，不能替代医生诊断或个体化治疗。不要自行购买或重复使用抗菌药、提前停药、共享处方、阴道冲洗或自行进行盆腔检查。

## 可能有哪些表现

PID 的表现可能较轻、不典型，甚至没有明显症状。可能出现：

- 下腹或盆腔疼痛；
- 阴道分泌物异常；
- 性交痛；
- 经间期或性交后出血；
- 排尿不适；
- 发热、寒战；
- 恶心或呕吐。[^2][^3][^4][^6]

这些症状并不特异。异位妊娠、阑尾炎、卵巢囊肿或扭转、尿路感染和子宫内膜异位症等也可能表现相似。疼痛剧烈或加重、伴高热、反复呕吐或明显虚弱，以及存在妊娠可能时，应及时接受医疗评估，不能只等待症状自行缓解。[^1][^3][^6]

## 医生怎样判断

没有一项检查能在所有情况下单独确认或排除 PID。医生通常会结合症状、妊娠可能、专业盆腔检查、阴道或宫颈标本、性传播感染检测，并按情况选择超声等检查。[^1][^3][^4]

衣原体或淋病检测阴性也不能完全排除上生殖道感染。由于延误治疗可能增加损伤，临床上会在符合情况时采用较低的治疗阈值，有时会在全部检查结果返回前开始经验性治疗；这不等于出现任何盆腔痛都应自行服用抗菌药。[^1][^4]

通常还会根据个人情况讨论淋病、衣原体、HIV 和梅毒检测。可参阅[衣原体感染](../otherbleed/chlamydia.md)、[淋病](../otherbleed/gonorrhea.md)、[HIV 感染与艾滋病](../otherbleed/hiv-aids.md)和[梅毒](../otherbleed/syphilis.md)。[^1]

## 为什么需要及时治疗

规范治疗可以清除当前感染并控制炎症，但不能逆转已经形成的输卵管瘢痕。PID 可能增加输卵管性不孕、异位妊娠和慢性盆腔痛的风险，反复发作时风险可能更高；这些是群体风险，不能据此预测每个人的结局。[^1][^2][^3][^5]

慢性盆腔痛并不自动表示仍有活动性细菌感染。治疗后持续或反复疼痛需要重新评估感染后损伤、子宫内膜异位症、盆底或其他原因，而不是反复自行使用抗菌药。[^3][^6]

输卵管卵巢脓肿可能需要住院、静脉治疗，少数情况下还需要引流或手术；具体处理由医疗团队根据病情决定，不能仅凭病灶大小或个人感觉自行判断。[^1][^4]

## 治疗后怎样随访

治疗方案需要覆盖多种可能病原体，并根据妊娠、过敏、病情严重程度和当地指南选择。本文不列抗菌药名称、剂量或疗程；应按处方完成治疗，不因症状提前改善而自行停药。[^1][^4]

CDC 和 ACOG 建议门诊治疗后约 72 小时（2～3 天）评估是否出现临床改善；如果没有改善，应尽快重新评估诊断、治疗方案和是否需要住院，而不是在家等待“满三天”才联系医生。[^1][^3]

治疗期间应避免性行为，直到本人完成治疗、症状缓解，并且需要处理的伴侣也已完成评估或治疗。衣原体或淋病相关 PID 通常建议约 3 个月后再次检测，以发现再感染；具体时间可由当地医疗机构调整。[^1]

## 妊娠期需要注意什么

妊娠期疑似 PID 属于高风险情况。CDC 建议住院并由相关专科共同进行治疗和评估。妊娠或可能妊娠且出现盆腔痛或其他可疑症状时，应尽快就医，不要自行使用非妊娠期方案。[^1]

严重病情、不能排除需要手术的急症、输卵管卵巢脓肿、无法耐受门诊治疗或门诊治疗没有反应等，也可能需要住院；是否住院应由医疗团队判断。[^1][^4]

## 使用宫内节育器怎么办

确诊 PID 不意味着必须立即取出宫内节育器（IUD）。通常先开始规范治疗并密切随访；如果治疗后 48～72 小时仍没有改善，医生会结合病情和个人意愿考虑是否取出。不要自行拉扯节育器线或取出装置。[^1]

IUD 相关 PID 风险主要集中在放置后的约 3 周内，总体发生风险较低。[^1] 出现症状时仍需评估其他病因，不能把长期分泌物变化或疼痛一概归为“环发炎”。可参阅[宫内节育器相关出血](../otherbleed/iud-bleeding.md)。

## 怎样降低风险

- 正确且持续使用屏障措施；
- 根据个人暴露和所在地建议接受适用的性传播感染检测；
- 本人和需要处理的伴侣及时完成治疗；
- 不使用阴道冲洗来“消毒”或预防感染。[^1][^2][^3]

PID 可能增加异位妊娠风险，但出现盆腔痛并不能自行区分病因；有妊娠可能时应及时检测和就医。可参阅[宫外孕](../otherbleed/ectopic-pregnancy.md)。

## 就医前可以准备什么

- 记录疼痛开始时间、位置、程度和变化；
- 记录分泌物、出血、发热、排尿或性交相关症状；
- 说明最后一次月经、妊娠可能及避孕方式；
- 整理近期性传播感染检测、治疗和伴侣处理情况；
- 列出使用过的抗菌药、过敏史和其他药物。
