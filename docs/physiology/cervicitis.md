# 宫颈炎

宫颈炎是宫颈发生炎症的一组临床表现。医生在专业检查中可能看到宫颈管黏液脓性分泌物，或宫颈口轻触后持续易出血；这些表现需要结合病史和实验室检查判断，不能自行用棉签检查宫颈。[^1][^3]

衣原体和淋球菌是重要病原体，但并不是全部原因。滴虫、其他微生物、阴道菌群失衡以及冲洗或化学刺激等也可能相关，许多病例最终没有明确病原体。诊断宫颈炎不等于一定存在性传播感染，也不能据此推断伴侣不忠。[^1][^2][^3]

!!! info "健康教育提示"
    本文用于帮助理解宫颈炎的症状、检查和处理原则，不能替代医生诊断或个体化治疗。不要阴道冲洗、使用腐蚀剂、自行触碰宫颈，或自行购买所谓“全套支原体药”。

## 可能有哪些表现

宫颈炎常常没有明显症状。出现症状时，可能包括：

- 阴道分泌物与平常不同；
- 经间期出血；
- 性交后出血。[^1][^3]

这些表现并不特异，不能根据分泌物的颜色或气味自行确诊。阴道炎、宫颈柱状上皮异位、宫颈息肉以及宫颈癌前病变或癌症等也可能表现相似。[^1][^3][^4]

下腹或盆腔痛伴发热、反复呕吐、明显虚弱或症状加重时，应尽快接受医疗评估，以排查[盆腔炎性疾病](pelvic-inflammatory-disease.md)及其他病因。妊娠或可能妊娠时出现异常出血或盆腔痛，也应及时就医。[^1][^3]

## 医生怎样检查

病史和分泌物外观不能准确确定宫颈炎的病因。医生通常会结合窥器检查、妊娠可能，并按情况采集宫颈、阴道或适用的尿液标本进行核酸扩增检测。衣原体和淋球菌是常见检测对象，也会根据症状评估细菌性阴道病或滴虫感染。[^1][^2][^3]

滴虫湿片检查的检出能力有限；有症状但湿片阴性时，医生可能选择核酸检测或培养等其他方法。[^1]

宫颈炎还需要评估是否存在上生殖道感染。可参阅[衣原体感染](../otherbleed/chlamydia.md)和[淋病](../otherbleed/gonorrhea.md)。

不建议把解脲支原体、微小脲原体、`Mycoplasma hominis` 或 B 族链球菌等所谓“全套病原体”常规检测当作宫颈炎的标准评估。检测项目应由医生根据症状、暴露和当地指南选择。[^1][^6]

## 是否需要立即治疗

是否在检测结果返回前开始经验性治疗，取决于感染可能性、能否复诊、检测条件、妊娠情况和临床表现。风险较低且能够复诊的人，有时可以等待检测结果；并不是所有宫颈炎都使用同一种治疗。[^1][^2][^3]

本文不列抗菌药名称、剂量或疗程。确诊具体病原体后，医生会按相应指南治疗，并讨论哪些伴侣需要评估或处理。暂停性行为及复测安排也取决于病原体和当地方案，不应自行套用统一时间。[^1]

如果症状持续或复发，医生会先核对是否完成治疗、是否再次暴露以及已有病原体结果，并按情况考虑其他检测。反复或长期使用抗菌药的获益并不明确；感染评估阴性时，还需考虑柱状上皮异位、息肉或不典型增生等非感染原因。[^1][^3]

## “宫颈糜烂”是不是感染

宫颈柱状上皮异位也常被称为“宫颈糜烂”。它是一种常见的宫颈外观变化，与宫颈癌无关联；也不应仅凭这种外观把它判断为宫颈炎。部分人可能出现较多分泌物、性交后出血或不适；没有症状时通常不需要治疗，有症状时应先排除感染和其他病变。[^4][^5]

不要根据所谓“糜烂分度”自行接受消融或腐蚀性治疗。持续性交后出血、宫颈外观异常、溃疡、肿块或治疗后仍不改善，需要妇科评估。[^3][^4][^5]

## 宫颈炎与宫颈癌筛查

宫颈炎症状评估和宫颈癌筛查是不同问题。Pap 或 HPV 常规筛查不能代替对异常出血、分泌物或可疑宫颈外观的诊断评估；即使既往筛查正常，持续性交后出血或不明原因出血也应就医。可参阅[HPV 感染](hpv-infection.md)和[宫颈癌](../otherbleed/cervical-cancer.md)。[^3][^4]

妊娠期宫颈外观可能出现生理变化，检查和用药需要结合孕周及妊娠适用指南个体化处理，不要照搬非妊娠方案。[^1][^2]

## 就医前可以准备什么

- 记录分泌物、出血和疼痛出现的时间及变化；
- 说明最后一次月经、妊娠可能和避孕方式；
- 整理近期衣原体、淋病及其他感染检测结果；
- 告知既往宫颈筛查、宫颈病变或息肉情况；
- 列出近期使用过的抗菌药、阴道制剂和冲洗产品。
