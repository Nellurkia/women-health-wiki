# 子宫内膜增生

子宫内膜增生是子宫内膜腺体异常增殖的一组病变。临床管理需要区分“无非典型性增生”和“非典型增生/子宫内膜上皮内瘤变（EIN）”：前者长期进展风险通常较低但并非为零，后者属于子宫内膜样腺癌的癌前病变，需要更积极地排查并存癌并制定治疗方案。[^1][^2][^3][^4][^6]

EIN 与非典型增生在当前指南中常被作为同一高风险类别管理，但具体病理术语和诊断仍应以病理报告及专科解释为准，不能仅凭名称自行判断严重程度。[^3][^4][^6]

!!! info "健康教育提示"
    本文用于帮助理解子宫内膜增生的检查、风险分层和治疗原则，不能替代妇科诊断或个体化治疗。不要自行使用或停用孕激素，也不能因出血停止或超声提示内膜变薄而跳过组织病理随访。

## 可能有哪些表现和风险因素

最常见的表现是异常子宫出血，例如月经量增多、经期延长、经间期出血或绝经后出血；有些人也可能没有明显症状。[^4][^5]

长期缺少孕激素保护的雌激素作用是重要机制。肥胖、慢性无排卵或多囊卵巢综合征、围绝经期、未充分配伍孕激素的外源雌激素以及他莫昔芬使用等可能增加风险，但存在风险因素不等于一定会发生子宫内膜增生。[^4][^5]

可参阅[月经量过多](../aub/hmb.md)、[育龄期子宫异常出血](../aub/reproductive-age-disorders.md)和[多囊卵巢综合征](pcos.md)。子宫肌瘤、子宫内膜息肉和子宫腺肌病等也可能造成相似出血表现，不能仅凭症状区分。[^4][^5]

## 超声厚度能确诊吗

不能。超声可以观察子宫内膜厚度和宫腔情况，帮助决定是否需要进一步检查，但“内膜厚”本身不等于子宫内膜增生，也不能仅凭厚度判断有无非典型性或癌症。最终确诊和风险分层依赖子宫内膜组织病理。[^2][^4]

医生可能根据年龄、绝经状态、出血和风险因素安排子宫内膜取样。取样不足或结果不明确、怀疑局灶病变，或者需要更可靠地排查并存癌时，宫腔镜观察并定向取样可能更有价值。[^3][^4]

宫腔镜和刮宫可用于观察宫腔、取得组织或评估病变；后续治疗和随访仍需依据病理类别决定。[^3][^4]

## 无非典型性增生怎样管理

无非典型性增生的长期癌变风险通常较低，但并非为零，仍需要组织学复查。医生会结合出血、可逆风险因素、生育计划和能否可靠随访，讨论观察并处理相关风险因素，或采用个体化孕激素治疗。生活方式调整可以支持整体健康，但不能替代病理随访。[^4][^5]

RCOG 指南将左炔诺孕酮宫内缓释系统（LNG-IUS）列为无非典型性增生的一线药物治疗：与口服孕激素相比，它的病变消退率更高，出血表现和不良反应情况也更有利；不接受 LNG-IUS 者可讨论连续口服孕激素。实际选择仍需考虑禁忌、耐受性和个人偏好；本文不提供药物剂量或疗程。[^4]

无非典型性增生通常不把子宫切除作为一线治疗。如果病变进展为非典型性、经过充分治疗仍不消退、治疗后复发、出血持续，或无法完成必要监测，可与专科团队讨论手术。[^4]

## 非典型增生或 EIN 怎样管理

非典型增生/EIN 是子宫内膜样腺癌的癌前病变，确诊时还需重视可能已经并存的子宫内膜癌。宫腔镜观察并取样是排查并存癌的重要方法之一；检查和病理结果应由妇科肿瘤或相关专科团队综合判断。[^3][^4]

全子宫切除是该高风险病变的根治性治疗方案。子宫内膜消融不能用于替代治疗，因为它可能无法彻底处理病变，并影响后续组织学监测。[^3]

绝经后接受全子宫切除时，通常还会讨论同时切除双侧输卵管和卵巢。绝经前是否保留卵巢则需要共同决策，综合年龄、遗传或癌症风险、手术绝经的影响和个人偏好；不能把“完成生育”直接等同于必须切除卵巢。[^3][^4]

## 希望保留生育能力怎么办

希望保留生育能力或暂时不能手术者，需要先尽力排除已经存在的癌症，再由有经验的专科团队制定孕激素治疗和密切随访计划。保守治疗不等于风险消失，也不能只依靠症状改善或超声变化评估效果。[^3]

ACOG 建议在开始保守治疗后的 3～6 个月内重复组织学评估，以判断治疗反应；之后的监测频率根据病理结果、治疗反应和个人情况调整。该时间安排应由医疗团队落实，不应自行延后或用超声替代活检。[^3]

完成生育后是否接受手术，应结合持续或复发风险、病理结果和个人目标与专科团队讨论。[^3][^4]

## 什么时候就医

- 任何新的绝经后出血都应尽快接受妇科评估；
- 经间期或性交后出血持续、反复，或月经量越来越多时，应就医查明原因；
- 已确诊者出现持续出血、治疗后复发，或无法按计划完成病理复查时，应尽快联系原治疗团队。[^4][^5]

异常出血不等于子宫内膜增生或癌症。可参阅[子宫内膜息肉](endometrial-polyps.md)、[子宫肌瘤](uterine-fibroids.md)、[子宫腺肌病](adenomyosis.md)和[子宫内膜癌](../otherbleed/endometrial-cancer.md)。

## 就诊前可以准备什么

- 记录出血发生时间、持续天数、月经变化及绝经状态；
- 整理既往超声、宫腔镜、取样和病理报告；
- 说明是否有多囊卵巢综合征、长期无排卵或相关用药；
- 告知生育计划、避孕方式、激素或他莫昔芬使用情况；
- 记录是否能够按计划接受重复组织学评估。
