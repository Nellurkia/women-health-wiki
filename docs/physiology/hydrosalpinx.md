# 输卵管积液

输卵管积液也称输卵管积水。输卵管靠近卵巢的一端受损、堵塞后，液体可能积在管内，使输卵管扩张。积液可发生在一侧或两侧。很多人没有明显症状，在超声或生育检查时才发现。部分人会有盆腔痛或阴道分泌物变化。[^1]

!!! info "健康教育提示"
    本文可帮助理解检查报告和准备就医，不能替代专业诊断或个体化治疗。

## 为什么会出现积液

既往盆腔感染、手术后的粘连或子宫内膜异位症都可能与输卵管受损有关。检查报告提示积液时，还要结合病史和症状判断原因。单凭积液不能判断是否有正在发生的感染，也不能判断是否曾有性传播感染。若新出现盆腔痛，并伴发热或异常分泌物，应尽快就医评估[盆腔炎性疾病](pelvic-inflammatory-disease.md)等可能原因。[^1][^7]

## 怎样看检查报告

超声有时能看到扩张的输卵管。子宫输卵管造影可帮助判断输卵管是否通畅、是否扩张，以及有没有远端阻塞的表现。医生会结合症状、其他检查和生育计划解读结果，造影也可能出现假阳性。安排检查前可告诉医生是否有怀孕可能、疑似感染或既往过敏。腹腔镜属于有创检查，医生会根据具体情况判断是否需要。[^1][^2][^3]

## 对备孕和试管婴儿有什么影响

单侧积液时，自然妊娠的机会还取决于另一侧输卵管是否通畅，以及其他生育因素。双侧完全堵塞会影响自然受孕。体外受精（IVF，俗称试管婴儿）可以绕过输卵管，但仍需考虑积液对治疗结局的影响。输卵管受损还与[异位妊娠](../otherbleed/ectopic-pregnancy.md)风险增高有关。[^1][^2]

选择取决于年龄、卵巢储备、积液侧别和病变程度、其他生育因素以及本人意愿。偶然发现积液、没有症状且暂无生育计划时，可以先在门诊明确诊断，再讨论是否观察。对于希望自然受孕且损伤较轻的人，有时可以讨论修复手术，同时权衡再次堵塞和异位妊娠的风险。[^2]

如果不孕与输卵管积液有关，且计划做 IVF，世界卫生组织（WHO）建议在 IVF 前讨论切除或阻断患侧输卵管。这是一项条件性推荐，证据确定性极低，具体选择还要考虑粘连和手术风险。Cochrane 对随机试验的系统综述发现，相比不做手术，IVF 前切除患侧输卵管可能提高临床妊娠率，该比较的证据确定性为中等。关于活产、并发症和不同术式优劣的证据仍有限。[^4][^5]

## 何时就医

- **可能怀孕时尽快评估**：出现阴道出血、单侧下腹痛或肩尖痛，即使尚未验出怀孕，也应尽快联系医疗机构。若突发尖锐而剧烈的腹痛，同时非常头晕或昏厥，应立即呼叫急救。[^6]
- **盆腔痛加重时及时求助**：新出现盆腔痛并伴发热或异常分泌物，应尽快就医。若疼痛剧烈或持续加重，或伴高热寒战、明显不适或昏厥，应立即去急诊或呼叫急救。[^7]

就诊时可以带上超声或造影报告，尤其是报告中关于哪一侧有积液、另一侧是否通畅的信息。记录症状开始时间，并向医生说明既往盆腔感染或手术史以及当前的生育计划。[^1][^2][^3]
