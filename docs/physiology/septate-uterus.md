# 纵隔子宫

纵隔子宫是一种先天的子宫形态差异。子宫腔中间有一道组织分隔，可以只隔开一部分，也可以贯穿整个子宫腔。有些人没有症状，是在盆腔影像检查、备孕评估或妊娠检查时偶然发现。[^1][^2]

!!! info "健康教育提示"
    本文可帮助理解影像报告和准备就医，不能替代妇科、生殖医学科或产科评估。

## 怎样确认是子宫纵隔

医生需要同时观察子宫腔形状和子宫外轮廓，才能区分纵隔子宫、双角子宫和弓形子宫。分型体系不同，有些报告的用词也会不同。弓形子宫在美国生殖医学会（ASRM）的指南中通常被视为临床意义有限的形态差异。初步判断有疑问时，可以带上原始影像复核。[^1]

ASRM 指南优先推荐三维经阴道超声评估子宫形态，必要时可配合宫腔盐水灌注。医生也可能根据情况安排磁共振成像。单靠宫腔镜或子宫输卵管造影，无法同时充分看到宫腔和子宫外轮廓，分型可能需要其他影像。[^1]

## 对妊娠有什么影响

观察性研究发现，纵隔子宫与流产、早产和胎位异常风险增高有关。对个人来说，发现纵隔不能解释某一次流产，也不能预测下一次妊娠的结局。它是否会造成不孕，目前证据不足。有备孕困难或多次妊娠丢失时，医生还会评估其他可能因素。[^1][^3]

## 什么情况下会讨论手术

在妇科或生殖医学门诊，医生可根据影像和妊娠史讨论是否需要宫腔镜纵隔切开或切除。手术可能发生子宫穿孔、出血，有时还需要进一步处理。考虑手术时，可以请医生说明希望改善的结局、适用于自己病史的证据，以及手术可能带来的负担。[^1][^4][^5]

- **偶然发现，暂无备孕计划**：目前证据不足以支持预防性手术。可携带报告在门诊确认分型，需要时再讨论随访。[^1]
- **有不孕，但没有反复妊娠丢失**：世界卫生组织（WHO）有条件地建议不做宫腔镜纵隔切除，证据确定性低。ASRM 允许在充分告知活产获益尚不确定后，由患者和医生共同决定是否手术。[^1][^6]
- **有反复流产病史**：ASRM 把宫腔镜切开列为可以共同讨论的选项。欧洲人类生殖与胚胎学会（ESHRE）对疗效更审慎，认为应继续研究手术能否改善结局。[^1][^3][^7]

一项小型开放标签随机试验纳入有不孕、妊娠丢失或早产史的人，未发现切除纵隔能提高活产率。Cochrane 系统综述认为，随机证据确定性低，手术与观察相比，活产或持续妊娠可能差别不大。非随机研究的结果仍很不确定。即使有研究观察到流产减少，也需要单独验证手术是否增加活产。[^4][^5]

## 已经怀孕或做完手术怎么办

如果已经怀孕，可以在产检时向产科医生说明影像结果、既往妊娠结局和是否做过纵隔手术。后续评估取决于个人病史。孕期出现阴道出血，应及时联系产科。有大量出血，或出血伴严重腹痛、肩痛、明显头晕或昏厥，应立即呼叫急救。出现这些症状时需要评估其他可能原因，包括[异位妊娠](../otherbleed/ectopic-pregnancy.md)。[^1][^8]

宫腔镜术后如果出血明显增多、腹痛剧烈或逐渐加重，或出现发热，应联系手术团队或就医。复诊可带上原始影像、报告日期、手术记录和既往妊娠结局。[^1][^9]
