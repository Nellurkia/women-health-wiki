# 宫内节育器相关出血

宫内节育器（IUD）是放置在子宫腔内的长效可逆避孕方法，主要包括含铜 IUD 和释放左炔诺孕酮的 IUD（LNG-IUD）。两类 IUD 对月经的影响不同，判断出血是否属于常见适应过程，需要先明确使用的是哪一种。[^1][^2]

出血变化常见，不等于必须忍受。无论变化是否达到某个“严重程度”，都可以随时与医护人员讨论观察、处理、改用其他避孕方法或取出 IUD；是否继续使用应尊重本人意愿。[^2]

!!! info "健康教育提示"
    本文用于帮助理解 IUD 使用期间的出血变化和就医流程，不能替代医生的诊断或个体化治疗。不要自行拉扯尾丝或取出 IUD，也不要根据网络信息自行使用止血药或激素。

## 两类 IUD 的出血变化有什么不同

### 含铜 IUD

放置含铜 IUD 后最初 **3～6 个月**，可能出现点滴出血、月经量增加、经期延长或痛经加重。许多人的这些变化会随时间减轻，但并不保证每个人都会如此。[^2]

含铜 IUD 可能增加月经量；已有缺铁或贫血，或出现明显乏力等症状时，可以与医生讨论是否需要评估。但缺铁性贫血通常不会自动排除使用含铜 IUD。[^2]

### LNG-IUD

放置 LNG-IUD 后最初 **3～6 个月**，不规则点滴或少量出血很常见；随着使用时间延长，出血通常减少，部分人会出现月经稀少或闭经。持续的大量出血并不常见，需要评估其他原因。[^2]

LNG-IUD 使用期间的闭经通常不需要治疗，也不是“经血淤积”在子宫内。如果存在妊娠可能，应先排除妊娠；对闭经仍感到困扰时，也可以与医生讨论。[^1][^2]

月经量变化的记录方法可参阅[月经量过多](../aub/hmb.md)，其他育龄期异常出血可参阅[育龄期子宫异常出血](../aub/reproductive-age-disorders.md)。

## 哪些变化需要重新评估

已经使用 IUD 且出血稳定数月后，如果新出现大量或持续出血，或原有规律明显改变，不应简单归为“正常副作用”。医生会结合情况排查 IUD 移位或脱落、妊娠、性传播感染、甲状腺问题，以及子宫内膜息肉或子宫肌瘤等新发情况。[^2]

持续大量出血、严重盆腔疼痛，或出现发热、异常阴道分泌物时，应联系医疗人员评估。[^2]

相关疾病可参阅[子宫内膜息肉](../physiology/endometrial-polyps.md)、[子宫肌瘤](../physiology/uterine-fibroids.md)和[衣原体感染](chlamydia.md)。这些内链用于帮助理解不同原因，不能替代检查。

## 尾丝变化意味着什么

如果怀疑 IUD 位置异常，不要自行拉扯尾丝或取出 IUD，应联系医疗人员进行专业评估。不能仅凭自己是否摸到尾丝确定 IUD 位置。[^1][^2]

IUD 不会在身体里随意“游走”。子宫穿孔和 IUD 脱落属于少见并发症，但确实可能发生，需要通过专业评估确认，不能自行拉扯或重新放置。[^1]

## 使用 IUD 后验孕阳性怎么办

IUD 避孕效果很高，因此带器妊娠少见；但一旦带器验孕阳性，应尽快确认妊娠位置并排查异位妊娠。[^1][^2] 相关信息可参阅[子宫异位妊娠](ectopic-pregnancy.md)。

带器妊娠时是否以及怎样取出 IUD，必须由医疗人员根据妊娠位置、尾丝是否可见和个人计划处理。继续留置 IUD 与流产、感染和早产风险增加相关，但自行取出也可能造成伤害，不应自行操作。[^2]

## 感染、脱落和生育能力

IUD 本身不预防性传播感染。根据个人暴露情况，仍需使用安全套并按建议接受相关检测。放置后早期的盆腔感染风险会短暂增加，但总体较低；出现相关症状时应及时评估。[^1][^2]

如果诊断盆腔炎，并不必然需要立即取出 IUD。医生会根据治疗反应、本人是否希望继续使用和具体情况安排复评；不要自行取出。[^2]

IUD 不会导致不孕；既往或当前性传播感染等其他影响生育能力的因素，需要单独评估。[^1]

## 医生可能怎样处理出血

处理前需要先确认 IUD 类型、放置时间、出血模式和本人目标，并在需要时排除妊娠、感染、IUD 位置异常或其他妇科原因。[^2]

如果没有发现需要处理的其他原因，医生会与本人讨论继续观察、针对症状治疗、改用其他避孕方法或取出 IUD。本文不列药名、剂量或固定疗程，因为适用方案取决于 IUD 类型、健康状况和个人偏好。[^2]

希望取出 IUD 本身就是可以提出的需求，无需先证明出血“足够严重”。如果医护人员建议继续观察，也可以询问预计变化、复评时间、可选处理方式，以及哪些变化需要提前复诊。

## 就诊前可以准备什么

- 确认使用的是含铜 IUD 还是 LNG-IUD，以及放置日期；
- 记录出血日期、持续时间、出血量变化和伴随疼痛；
- 说明出血是否在稳定数月后突然改变；
- 告知近期妊娠可能、性传播感染暴露和验孕结果；
- 记录尾丝是否出现变化，但不要反复探查或拉扯；
- 说明希望继续使用、尝试处理、换方法还是取出。

常见的适应期变化可以观察，但个人感受和避孕目标同样重要。出血令人困扰时，可以主动寻求帮助，不必独自忍受。
