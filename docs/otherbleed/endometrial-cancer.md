# 子宫内膜癌

子宫内膜癌是发生在子宫内膜的恶性肿瘤。子宫内膜位于子宫腔内，随月经周期发生变化；它与发生在子宫颈的[宫颈癌](cervical-cancer.md)不是同一种疾病，病因、检查和治疗方式也不同。[^1][^4]

异常阴道出血是子宫内膜癌常见的就医线索，但 **异常出血不等于癌症**。息肉、肌瘤、激素变化等许多良性情况也可能引起出血，需要通过医学评估查明原因。[^2][^3]

!!! info "健康教育提示"
    本文用于帮助理解子宫内膜癌及就医流程，不能替代医生的诊断或个体化治疗。不要根据出血量、超声内膜厚度或肿瘤标志物自行判断是否患癌。

## 哪些表现需要及时评估

以下情况应及时预约妇科评估：

- **绝经后出现任何阴道出血或点滴出血**；
- 两次月经之间出血；
- 月经出血持续时间或出血量明显异常；
- 持续出现水样、粉红色或带血的阴道排液；
- 盆腔疼痛或压迫感等持续不适。[^1][^3]

这些表现并非子宫内膜癌特有，出现其中一项不能自行诊断癌症。但尤其是绝经后出血，即使量少或只发生一次，也值得及时说明给医生。已经出现症状时，不应等待所谓“常规筛查”或自行反复观察。[^2][^3]

月经量明显增加可参阅[月经量过多](../aub/hmb.md)，其他育龄期异常出血可参阅[育龄期子宫异常出血](../aub/reproductive-age-disorders.md)。子宫内膜息肉和子宫肌瘤也可能引起异常出血，但症状不能用于自行区分，可分别参阅[子宫内膜息肉](../physiology/endometrial-polyps.md)和[子宫肌瘤](../physiology/uterine-fibroids.md)。

## 哪些因素与风险增加相关

子宫内膜癌风险与年龄增长、肥胖或代谢健康问题、较长时间缺乏孕激素拮抗的雌激素暴露、部分药物，以及林奇综合征等遗传易感因素相关。既往病史、生育史和家族史也可能影响医生对风险的判断。[^1][^2][^4]

风险因素是人群层面的关联，不代表具有某项因素就一定会患癌，也不代表没有已知因素就不会患病。体重、是否生育或用药经历都不应成为责备患者的理由。正在使用他莫昔芬或其他可能影响子宫内膜的治疗时，不应自行停药；出现异常出血应联系开药医生或妇科评估。[^1][^4]

## 有常规筛查吗

目前没有被证实适用于平均风险、没有症状人群的标准常规子宫内膜癌筛查方法。对无症状人群进行常规检查是否能够降低死亡风险，现有证据不足；因此，认识异常出血并及时就医十分重要。[^2]

需要注意：

- **宫颈细胞学检查不是子宫内膜癌筛查。**[^2]
- **盆腔或阴道超声不能单独确诊子宫内膜癌。** 超声可提供子宫内膜和盆腔结构线索，但结果需要结合症状、年龄和后续检查解释。[^1][^2]
- 不应根据一个“内膜厚度”数字或肿瘤标志物结果自行排除或确认癌症。是否需要取样由医生结合整体情况决定。[^1]

林奇综合征或其他明确遗传高风险人群的监测和风险降低方案不同于平均风险人群，应由熟悉遗传性肿瘤的团队个体化制定。[^2][^5]

## 医生怎样评估异常出血

医生通常会了解出血发生时间、是否已经绝经、月经和妊娠情况、药物与激素使用、既往疾病及家族史，并根据个人情况进行体格检查。超声可以帮助观察子宫内膜及其他盆腔结构，但不能替代组织诊断。[^1][^3]

当需要排查子宫内膜病变时，医生可能安排子宫内膜取样、宫腔镜或诊断性刮宫等检查。**是否为癌症最终依赖组织病理学检查。** 取样方式由医生根据症状、影像、既往结果和个人情况选择。[^1][^4]

一次检查未发现癌症并不意味着持续或反复出血可以忽略。如果症状继续存在或再次出现，应把变化告诉医生，由医生判断是否需要进一步检查或重新取样。[^1][^3]

## 确诊后还需要了解什么

病理检查会确定肿瘤的组织学类型和分级。医生还会评估疾病范围并进行分期；在适用情况下，分子检测结果也可能帮助判断预后和选择治疗。治疗方案需要综合病理、分期、分子特征、整体健康状况和个人目标。[^1][^4][^5]

患者可以向医疗团队询问：

- 病理类型、分级和分期分别意味着什么；
- 是否进行了与治疗决策相关的分子或遗传评估；
- 推荐方案的目标、可能获益和不良反应；
- 治疗对生育、性健康、绝经症状和日常生活的影响；
- 是否适合多学科会诊或获得第二诊疗意见。

## 治疗原则

手术是许多子宫内膜癌的重要治疗方式。根据病理类型、分期、复发风险和身体状况，还可能使用放射治疗、化学治疗、激素治疗、靶向治疗、免疫治疗或支持照护。不同方法可单独或联合使用，具体由专业团队制定。[^1][^4][^5][^6]

本文不提供药物剂量、疗程或手术范围。治疗选择可能随新的病理或分子结果调整，不应根据网络信息自行选择、推迟或停止治疗。

## 生育保留需要特别谨慎

标准治疗可能影响生育能力。只有极少数经过严格筛选、病变特征合适且希望保留生育能力的人，才可能在妇科肿瘤、生殖医学和病理等多学科团队共同评估后讨论保守治疗。[^1][^5][^6]

生育保留并不是“先吃药观察”这么简单，通常需要充分知情讨论、规范治疗以及反复的子宫内膜取样和密切随访。如果治疗没有达到预期、病变进展或完成生育计划，团队可能建议转为标准治疗。是否符合条件必须由专业团队判断，不能凭超声或一次活检自行决定。[^1][^5]

## 遗传咨询与家人健康

部分子宫内膜癌与林奇综合征等遗传易感有关。医生可能结合确诊年龄、病理或分子结果、本人其他肿瘤史及家族史，建议遗传咨询或检测。遗传结果可能影响本人治疗、后续肿瘤风险管理，也可能为血缘亲属提供健康信息。[^1][^4][^5]

是否检测、检测哪些基因以及怎样告知家人，均应在知情同意和隐私保护的基础上个体化讨论。没有明显家族史也不能仅凭这一点排除遗传风险。

## 就诊前可以准备什么

- 记录每次出血或排液的日期、持续时间和变化趋势；
- 说明是否已经绝经，以及最后一次正常月经时间；
- 列出正在使用的处方药、非处方药、激素和补充剂；
- 整理既往子宫内膜检查、超声、病理和治疗资料；
- 了解近亲属中结直肠癌、子宫内膜癌及其他相关肿瘤史。

不必为了记录得更“准确”而推迟就医。对绝经后出血或持续异常出血，及时获得专业评估比自行估算出血量更重要。
