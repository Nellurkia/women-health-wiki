# 经前期综合征（PMS）

经前期综合征（premenstrual syndrome，PMS）是指一组在月经前反复出现、月经开始后减轻或消失，并对日常生活造成影响的身体或情绪症状。症状常在月经前 **1～2 周**出现，但具体时间和表现因人而异。[^1][^2]

偶尔在经前感到轻微不适，并不自动等于患有 PMS。判断重点不只是“有没有症状”，还包括症状是否按周期反复、是否在月经后缓解，以及是否影响学习、工作、人际关系或生活质量。

!!! info "健康教育提示"
    本文用于帮助理解经前症状和就医流程，不能替代专业诊断或个体化治疗。不要根据症状清单自行使用处方药或激素。

## 常见表现

PMS 的表现可以同时涉及身体和情绪，并可能在不同周期有所变化。

### 身体症状

- 乳房胀痛；
- 腹胀、体重暂时变化；
- 头痛；
- 疲劳或睡眠变化；
- 食欲或食物偏好变化；
- 关节、肌肉或背部不适。[^1][^2]

### 情绪和行为变化

- 易怒、情绪波动；
- 情绪低落、焦虑或紧张；
- 注意力下降；
- 对日常活动兴趣下降；
- 感到不知所措；
- 与他人相处更困难。[^1][^2]

这些症状并非 PMS 特有。疼痛明显时可同时参阅[痛经](period-pain.md)；月经周期的基本概念可参阅[月经基础知识](../basic/menstrual-basic.md)。经前症状是真实的健康体验，但不意味着一个人“脆弱”或“情绪化”，相关误解可参阅[月经不是什么](../basic/no-s.md)。

## PMS 和 PMDD 有什么不同

经前烦躁障碍（premenstrual dysphoric disorder，PMDD）是一种更严重的经前障碍。它通常以明显的抑郁、焦虑、易怒或情绪不稳定等症状为主，并显著影响工作、学习、人际关系或日常功能。[^3]

症状严重并不代表一定是 PMDD。抑郁症、焦虑障碍等问题也可能在经前加重，且症状可能在整个月经周期中持续存在。是否符合 PMDD 或其他诊断，需要医疗或心理健康专业人员结合症状时间、严重程度和功能影响进行评估。[^1][^3]

## 怎样记录症状

如果怀疑 PMS 或 PMDD，可以每天记录症状，而不是只在症状最明显时回忆。建议至少连续记录 **两个完整月经周期**，这有助于确认症状是否稳定出现在经前并在月经后缓解。[^1]

记录内容可以包括：

- 月经开始和结束日期；
- 每种身体、情绪和行为症状的严重程度；
- 症状对睡眠、学习、工作、关系和日常活动的影响；
- 正在使用的药物、激素或补充剂；
- 当天发生的重要压力事件或其他健康变化。

可以使用纸质日历、手机备忘录或医生建议的症状记录表。持续记录比单次回忆更有助于区分周期性经前症状和整个月都存在的问题。

## 医生如何评估

PMS 和 PMDD 没有一项能够单独确诊的血液、激素或影像学检查。评估通常依据症状记录、月经周期模式、功能影响和病史。医生可能根据具体情况排查其他会引起相似症状的疾病，但这些检查用于寻找其他原因，不是“PMS 检测”。[^1][^2]

就诊时，医生还可能了解：

- 症状是否只在经前出现、月经后是否有无症状期；
- 症状是否在整个月持续，仅在经前加重；
- 既往或当前的抑郁、焦虑及其他心理健康状况；
- 使用的避孕方式、药物和补充剂；
- 症状对生活功能和人际关系的具体影响。

## 自我照护

规律运动、均衡饮食、充足睡眠、减少压力，以及限制可能加重个人症状的咖啡因，可能帮助部分人减轻经前不适，但效果因人而异。[^1][^2]

可以先结合症状记录，观察哪些生活调整与改善相关。不要把症状归咎于“意志力不足”；如果自我照护后仍明显影响生活，应寻求专业帮助。

维生素、矿物质、草药或其他补充剂对 PMS 的效果证据有限，并可能与药物相互作用。使用前应向医生或药师说明正在服用的全部药物和补充剂。[^1]

## 专业治疗

治疗需要根据主要症状、严重程度、是否需要避孕、既往健康情况和个人偏好共同决定，可能包括：

- **认知行为治疗（CBT）**：可帮助识别和调整与症状相关的思维及应对方式；
- **选择性5-羟色胺再摄取抑制剂（SSRI）**：可用于部分严重 PMS 或 PMDD。Cochrane 系统综述认为，与安慰剂相比，SSRI 可能改善总体经前症状（中等确定性证据），但也可能增加不良反应，较常报告恶心、乏力或能量下降和嗜睡，使用前应与医生权衡。[^1][^4]
- **某些激素避孕方法**：可能适用于部分人，但效果、禁忌和风险需要个体化评估。[^1][^2]

处方药的使用时间和方案可能因人而异。本文不提供具体药名、剂量或疗程；请由医生评估药物相互作用、禁忌和随访需要，不要自行开始、停用或更改处方治疗。

## 什么时候需要就医

出现以下情况时，建议预约妇科、全科或心理健康专业人员评估：

- 经前症状反复影响学习、工作、关系或日常生活；
- 情绪低落、焦虑、愤怒或失控感明显；
- 症状并非只在经前出现，而是整个月都存在；
- 自我照护无法改善症状；
- 不确定症状来自 PMS、PMDD，还是其他身体或心理健康问题。[^1][^2][^3]

### 出现自伤或自杀想法时

PMDD 可能伴随自杀想法。[^3] 无论是否已确诊 PMDD，如果出现自伤或自杀想法，应立即告诉一位可信任的人，并尽快联系医疗或心理健康专业人员。若已经有立即伤害自己的危险、计划或正在实施的行为，应联系当地急救服务或立即前往急诊，并尽量不要独处。[^5]
